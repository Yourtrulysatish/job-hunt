# Mode: Negotiate — Offer Negotiation Playbook

## When triggered

- "I got an offer from [company]"
- "They offered me [X], is that good?"
- "How do I negotiate this?"
- "They're giving me geographic discount"
- "I have a competing offer"

---

## Step 2 — Benchmark

Use WebSearch: Glassdoor, Levels.fyi, LinkedIn Salary, Blind for this exact role+company+location.

**Total Compensation (TC) calculation:**
```
TC = Base + (RSU value / vesting years) + Bonus (target) + Benefits estimate
```

**Market position:** P25 / P50 / P75 / P90

---

## Step 3 — Counter-offer Math

**Target:** Aim for P75 minimum. Calculate the ask:

| Component | Current offer | Market P75 | Gap | Counter |
|-----------|--------------|------------|-----|---------|
| Base | | | | |
| RSUs (annual) | | | | |
| Total | | | | |

**Counter range:** `[P75, P90]` — ask for P90, accept at P75.

---

## Step 4 — Negotiation Scripts

### Opening counter (email)
> Thank you for the offer — I'm genuinely excited about the role and the team.
>
> I've done my research and based on [Levels.fyi / competing offers / market data for this role in [location]], I was expecting a total comp closer to [target]. The offer is [X]% below that.
>
> Would the team have flexibility to [specific ask — base to X, or RSUs to Y]? I want to make this work.

### Geographic discount pushback
> My impact and output are location-agnostic. The market data I'm looking at — Levels.fyi, Glassdoor — reflects the role's market value regardless of where I sit. I'd like to explore whether we can align on the role's value rather than my zip code.

### Competing offer leverage
> I want to be transparent — I'm also in final stages with [Company B]. I have a strong preference for [this company] because of [specific reason]. If we can close the gap on comp, the decision is easy for me.

### Signing bonus as bridge
> If base flexibility is limited, would a signing bonus bridge the gap for the first year? It costs the company less long-term and lets us move forward.

### Equity ask (if not offered or low)
> What does the equity refresh schedule look like after the first grant? And can you share the strike price / current 409A valuation?

## Step 5 — Decision Framework

After negotiation, help the user decide:

| Factor | Weight | Score (1–5) | Weighted |
|--------|--------|-------------|---------|
| Total comp vs market | 30% | | |
| Role growth potential | 25% | | |
| Team / manager quality | 20% | | |
| Product / mission fit | 15% | | |
| Work-life balance signals | 10% | | |

Score ≥ 4.0 → accept. 3.5–3.9 → negotiate harder. < 3.5 → walk away unless exceptional circumstances.

---

## Rules

- **Never accept on the spot** — always ask for 48–72 hours minimum
- **Get everything in writing** before giving notice at current job
- **Equity is negotiable more often than base** — companies prefer this
- **Never reveal your bottom line**
- **Be warm, not adversarial** — you're about to work with these people
